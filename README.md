# AI Voice Bridge

**Создано by ridfers.** Приложение для Windows передаёт выбранный звук из CS2, Dota 2 или Discord в голосовой чат ChatGPT через виртуальный микрофон. Ответы ChatGPT можно слышать в наушниках и отправлять в игровой голосовой чат.

> Программа не использует API ChatGPT / OpenAI и не требует API-ключа. Звук передаётся через виртуальные аудиоустройства в голосовой сеанс ChatGPT, открытый в браузере.

## Установка

1. Скачайте **AI-Voice-Bridge-v0.2.0-windows-x64.zip** из Releases и распакуйте папку целиком.
2. Установите [.NET 10 Desktop Runtime x64](https://dotnet.microsoft.com/en-us/download/dotnet/10.0). Для схемы ниже нужны [Voicemeeter Banana](https://vb-audio.com/Voicemeeter/banana.htm) и [VB-CABLE](https://vb-audio.com/Cable/).
3. Откройте `AI Voice Bridge.exe` из распакованной папки. Драйверы поставляются отдельно.

Для захвата отдельного приложения нужна Windows сборки **20348** или новее. Режим «Все приложения» захватывает звук выбранного устройства. Сборка релиза предназначена для Windows x64.

## Настройка Banana

| Источник | Куда направить звук |
| --- | --- |
| Игра или Discord в режиме «Все приложения» | Вывод приложения → **CABLE Input**. В Banana назначьте **CABLE Output** одному из аппаратных входов и включите на нём только **A1**. |
| Мост → ChatGPT | В мосте выберите выход **Voicemeeter Input**. У полосы VAIO включите **B1**, отключите A1 и B2. В браузере у ChatGPT выберите вход **Voicemeeter Out B1**. |
| ChatGPT → игра и наушники | Для браузера назначьте вывод **Voicemeeter AUX Input**. На AUX включите **A1** и **B2**, отключите B1. В игре выберите **Voicemeeter Out B2**. |
| Ваш микрофон | Назначьте аппаратному входу Banana и отключите для него **B1**. Кнопка «Мой голос в игре» управляет отправкой этого входа в B2. Для независимой работы Discord выберите в нём физический микрофон. |

Для A1 выберите наушники. В мосте во вкладке «Аудио» укажите физический микрофон, **CABLE Input** для общего звука, **Voicemeeter Input** для выхода в ChatGPT и **Voicemeeter AUX Input** как источник браузера. При внешней маршрутизации через Banana оставьте дополнительные маршруты и мониторинг в мосте выключенными. Кнопка Potato предназначена для отдельной редакции Voicemeeter и для этой схемы не нужна.

В режимах «Только CS2», «Только Dota 2» и «Только Discord» Windows захватывает звук выбранного процесса независимо от его устройства вывода. Запустите нужное приложение, выберите его в мосте, нажмите «Запустить» и удерживайте MOUSE5 либо включите передачу кнопкой. В игре используйте её штатную клавишу голосового чата.

Кнопка «Проверить звук» открывает локальную страницу, которая показывает сигнал на виртуальных микрофонах B1 и B2. Страница показывает уровни Windows. Получение и распознавание звука ChatGPT можно проверить в самом голосовом сеансе. Для проверки голоса ИИ на B2 оставьте «Мой голос в игре» выключенным.

## Сборка из исходников

Требуется [.NET 10 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/10.0).

```powershell
dotnet build "AI Voice Bridge.csproj" -c Release
dotnet publish "AI Voice Bridge.csproj" -c Release -r win-x64 --self-contained false -o artifacts/windows-x64
```

Тесты запускаются командой `dotnet run --project "Tests/AI.VoiceBridge.Tests.csproj" -c Release`. Аппаратные проверки рассчитаны на локальную машину с настроенным Voicemeeter и MCHOSE X9.
